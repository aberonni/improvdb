# ImprovDB

An open database of improv games, exercises and formats, and the lesson plans teachers build from them.

## Language

### Resources

**Resource**:
A single improv activity in the database: an Exercise, a Short Form game or a Long Form format. Internal and code term only; in user-facing copy call them "games & exercises".
_Avoid_: Activity, item (internal); "resource" (user-facing)

**Exercise**:
A Resource used to train a skill or warm up a group, not performed for an audience.
_Avoid_: Drill

**Short Form game**:
A Resource that is a short, structured scene game with a fixed rule or gimmick.
_Avoid_: Game (on its own, when the type matters)

**Long Form format**:
A Resource describing the structure of an extended improvised piece.
_Avoid_: Long form game

**Category**:
A skill or theme a Resource practises (e.g. listening, agreement). A Resource can have several.
_Avoid_: Tag, topic

**Catalogue**:
The filterable list of all published Resources. It is the home page.
_Avoid_: Browse page, resource list

**Landing Page**:
A Catalogue view fixed to one type or one Category, with its own heading and introduction, meant to be found through search.
_Avoid_: Hub, filtered page, SEO page

### Lesson plans

**Lesson Plan**:
An ordered selection of Resources a teacher assembles for a class.
_Avoid_: Session plan, class plan
