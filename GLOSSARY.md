# ImprovDB

An open database of improv games, exercises and formats, and the lesson plans teachers build from them.

## Language

### Resources

**Resource**:
A single improv activity in the database: an Exercise, a Short Form game or a Long Form format. Internal and code term only; in user-facing copy say "games & exercises" (singular: "game or exercise"), or use the Resource's own title.
_Avoid_: Activity, item (internal); "resource" (user-facing)

**Exercise**:
A Resource used to train a skill or warm up a group, not performed for an audience.
_Avoid_: Drill

**Short Form game**:
A Resource that is a short, structured scene game with a fixed rule or gimmick.
_Avoid_: Game (on its own, when the type matters)

**Long Form format**:
A Resource describing the structure of an extended improvised piece.
_Avoid_: Long form game

**Category**:
A skill or theme a Resource practises (e.g. listening, agreement). A Resource can have several.
_Avoid_: Tag, topic

**Catalogue**:
The filterable list of all published Resources. It is the home page.
_Avoid_: Browse page, resource list

**Landing Page**:
A Catalogue view fixed to one type or one Category, with its own heading and introduction, meant to be found through search.
_Avoid_: Hub, filtered page, SEO page

### Resource lifecycle

**Draft**:
A Resource not yet visible to visitors, and not an Edit Proposal: newly submitted by a contributor, created by an admin but not published, or unpublished. In user-facing copy a contributor's Draft is a "Proposal".
_Avoid_: Proposal (internal), pending, unpublished resource

**Published**:
The state of a Resource visitors can see and find in the Catalogue.
_Avoid_: Live, public

**Edit Proposal**:
A contributor's suggested changes to an existing Resource, waiting for an admin to accept or reject them. It is never published itself.
_Avoid_: Proposed edit, suggestion, change request

**Accept**:
An admin applying an Edit Proposal's changes to its original Resource, which ends the Edit Proposal.
_Avoid_: Approve, merge

**Reject**:
An admin discarding an Edit Proposal without applying it.
_Avoid_: Decline, deny

### Lesson plans

**Lesson Plan**:
An ordered selection of Resources a teacher assembles for a class.
_Avoid_: Session plan, class plan
